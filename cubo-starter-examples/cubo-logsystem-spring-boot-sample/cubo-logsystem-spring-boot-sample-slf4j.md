# 日志系统示例（SLF4J）

基于 SLF4J 的最简日志示例，展示 `cubo-logsystem-simple` 的基础日志能力，适合对日志功能要求较简单的场景。

## 运行方式

```bash
mvn spring-boot:run
```

## 演示特性

- SLF4J 标准日志接口使用
- 结构化日志输出格式
- 链路追踪日志上下文
