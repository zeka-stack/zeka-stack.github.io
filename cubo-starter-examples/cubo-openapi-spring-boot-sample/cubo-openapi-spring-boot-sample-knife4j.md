# OpenAPI 示例（Knife4j）

基于 Knife4j 的 API 文档示例，展示 `cubo-openapi-knife4j-spring-boot-starter` 自动生成和展示 OpenAPI 文档的能力。

## 运行方式

```bash
mvn spring-boot:run
```

启动后访问文档页面：http://localhost:8080/doc.html

## 演示特性

- Knife4j 增强型 API 文档自动扫描和生成
- RESTful 接口文档注解使用方式
- 文档页面在线调试功能
