# LLMs.txt

文档站通过 `vitepress-plugin-llms` 在构建时生成：

| 入口 | 用途 |
| --- | --- |
| [llms.txt](/llms.txt) | 文档导航与 Agent 阅读顺序 |
| [llms-full.txt](/llms-full.txt) | 全部站点正文，较大，按需读取 |
| [For Agents Markdown](/ai/index.md) | 接入说明与提示词 |
| [arch.md](https://zekastack.dong4j.site/docs/arch.md) | 工程规范 |
| [SKILL.md](https://zekastack.dong4j.site/docs/SKILL.md) | 业务开发工作流 |
| [starter Skills 索引](/skills/llms.txt) | 按实际组件选择独立 Skill |
| [业务范例](https://zekastack.dong4j.site/docs/zeka-demo.md) | 完整代码与集成验收说明 |

优先读索引与 `arch.md`，再读取实际依赖组件的 Skill 和页面 Markdown，避免把全部全文无差别塞入上下文。站点模块文档从源码 README/docs 同步；历史设计资料和教程不是当前 API 的兼容承诺。

维护者先执行根目录 `make ai-generate`，再执行站点同步与构建。插件会为页面生成 `.md`；公开的 arch/Skill/范例来自生成脚本。地址与站点 `base: /docs/` 一致，部署后以实际 HTTP 响应验证。
