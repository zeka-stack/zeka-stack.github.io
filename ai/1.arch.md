# arch.md 工程语言

`arch.md` 定义 Zeka Stack 业务项目的分层、命名、对象模型、组件选择、编码范式和验证要求。它承担后端框架中类似设计语言的作用，统一 AI 生成代码的基础约定。

[读取完整 arch.md](https://zekastack.dong4j.site/docs/arch.md) · [完整账户模块范例](https://zekastack.dong4j.site/docs/zeka-demo.md)

维护源是框架仓库根目录 `arch.md`；站点公开文件和 CLI 内嵌副本由生成脚本同步，避免各个通道出现不同版本。

## 主要内容

- parent / BOM / 组合 starter 的选择，避免依赖聚合 POM 或混用 Servlet / Reactive。
- ZekaStarter、根包扫描与响应包装的运行条件。
- Controller / Service / DAO 分层和 PO / Form / Query / DTO / Converter 范式。
- Result 自动包装、BaseCodes / LowestExceptionAssert、参数校验与事务边界。
- BasePO / BaseWithTimePO / BaseWithLogicPO / BaseExtendPO 的差别。
- 可直接复用的工具、字典、消息、日志与测试能力。
- 不允许 AI 自行发明的接口、配置和重复基础设施。

`zeka arch` 返回同一份规范，`zeka demo` 返回包含完整 import 和注释的业务范例。索引中的公开类型不等于任意业务模块都已依赖这些类型，使用前仍需查 starter 的依赖图。
